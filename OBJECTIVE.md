# Objective

Establish Codex Thinking Knob as a dependable, independently adoptable Astra
capability that users can discover through ToolboxMD, activate in a supported
Codex App Server client, use in ordinary work, and remove cleanly.

The Objective is complete when:

- A versioned release has documented compatibility and reproducible
  installation and launcher setup. Selective ToolboxMD Marketplace
  installation and direct artifact installation deliver the same release
  without requiring other ToolboxMD modules.
- Astra can request low, medium, high, or max effort within its active turn
  under the user's chosen policy. The wrapper preserves unrelated client
  behavior, settings, and tasks.
- Deterministic proof covers the runtime contract and failure behavior. Real
  work verifies that accepted effort changes reach subsequent model requests
  while the requested work completes. Reports distinguish accepted changes
  from verified execution.
- A fresh supported installation works through the documented public path,
  and removal affects only the wrapper and its owned setup. Public capability
  and efficiency claims are limited to the available evidence.

General model routing, mandatory review orchestration, global instruction
replacement, and automatic integration with an unmodified desktop application
are outside this milestone.
